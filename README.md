# madhanselvam.tech

Personal website for Madhan Selvam: Expert Engineer across Data, AI, Cloud, Architecture, and Platforms.

## Stack

- Next.js App Router
- TypeScript
- CSS design system
- MDX-ready content areas
- Resume and future AI content routes

## Structure

`src/app/` application routes and visual system
`src/components/` reusable interface components
`src/content/` projects, writing, and profile content
`src/blog/` future writing route
`src/ai/` future AI-ready routes and embedding workflows
`public/` static assets and resume

## Local development

```bash
npm install
npm run dev
```

Open http://localhost:3000.
